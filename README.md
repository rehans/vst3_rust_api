# VST 3 Rust API

## Introduction

This crate takes the offical VST 3 C API and generates the Rust API using `bindgen`.

## Get Started

```cmd
git clone https://github.com/rehans/vst3_rust_api.git
cd vst3_rust_api
cargo build
```

Find `target/vst3_bindings.rs` afterwards.
